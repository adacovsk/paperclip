# Plugin Authoring Smoke Example

A minimal plugin generated by `create-paperclip-plugin`, kept in the repo to check that the scaffold still builds and tests. It is not one of the bundled examples.

## Development

```bash
pnpm install
pnpm dev            # watch builds
pnpm dev:ui         # local dev server with hot-reload events
pnpm test
```

## Install Into Paperclip

With the server running, from the repo root:

```bash
pnpm --filter @paperclipai/plugin-authoring-smoke-example build
pnpm paperclipai plugin install ./packages/plugins/examples/plugin-authoring-smoke-example
```

## Build Options

- `pnpm build` uses esbuild presets from `@paperclipai/plugin-sdk/bundlers`.
- `pnpm build:rollup` uses rollup presets from the same SDK.
